# howtoopen-static-sites
this is a howto on how to open an html file as a web domain

How to (A)
Use A when you DON'T own the repository

Req: It has an html file, and doesn't have other file types included besides readme

1A. copy html file name on repository
2A. enter [username].github.io/[repository name]/[html file name]
3A. If something loads, congrats, your smart and you have common sense

---------------------------

Use B when you OWN the repository

Req: a html file and github pages on branch "main"

1B. open github pages
2B. go to your github site
3B. after the [repository name] of your github pages url, enter your [html file name] after words
4B. If something loads, but incorrectly, your on the right track.
