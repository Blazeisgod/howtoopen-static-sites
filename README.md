# howtoopen-static-sites
this is a howto on how to open an html file as a web domain

How to (A)
Use A when you DON'T own the repository

Req: It has an html file, and doesn't have other file types included besides readme

 1A. copy html file name on repository 
 
 2A. enter [username].github.io/[repository name]/[html file name]
